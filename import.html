Each AI emails you a download link. Menu names may differ slightly.

ChatGPT

Email in minutes
  1. On chatgpt.com, click your profile picture → Settings
  2. Data controls → Export data → Confirm export
  3. Open the email from OpenAI and download the .zip

Claude

Email in minutes
  1. On claude.ai, click your name → Settings
  2. Privacy → Export data
  3. From the email, download conversations-000.zip (and -001, -002… if there are more)
  4. If a file ends in .dms, rename it to .zip

Gemini

Can take hours
  1. Go to takeout.google.com → Deselect all
  2. Tick My Activity; under "All activity data included" choose only Gemini Apps
  3. Under "Multiple formats", set Activity records to JSON
  4. Create the export and download the .zip
