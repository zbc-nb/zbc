Import your real AI history

See the footprint of chats you had before installing PromptPrint.

🔒 Your files never leave this computer. PromptPrint reads them right here in your browser, keeps only the date, AI, task category and length of each prompt, and throws the text away.

Step 1: Download your history

Each AI emails you a download link, usually within a few minutes (sometimes longer). Menu names may differ slightly.

ChatGPT

  1. On chatgpt.com, click your profile picture → Settings
  2. Data controls → Export data → Confirm export
  3. Open the email from OpenAI and download the .zip file

Claude

  1. On claude.ai, click your name → Settings
  2. Privacy → Export data
  3. Open the email from Anthropic. If you get a list of several files, download only conversations-000.zip (and -001, -002… if there are more)
  4. If a file ends in .dms, rename it to .zip

Gemini experimental

  1. Go to takeout.google.com and click Deselect all
  2. Tick My Activity. Under "All activity data included", choose only Gemini Apps
  3. Under "Multiple formats", set Activity records to JSON
  4. Create the export and download the .zip
